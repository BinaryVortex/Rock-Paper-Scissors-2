## About
This is a lightweight implementation of the classic Rock Paper Scissors game. It demonstrates DOM manipulation, event handling, simple game logic, and basic styling — ideal for beginners learning front-end development.

## Demo / Screenshot
The screenshot above shows the game UI and a sample round. To see the game in action, open `index.html` in your browser (no server required).

## Features
- Quick, responsive UI
- Score tracking for the player and computer
- Simple, readable codebase for learning
- Works offline (open the HTML file locally)

## How to Play
1. Open the game in your browser.
2. Click one of the choices: Rock, Paper, or Scissors.
3. The computer will randomly choose its option.
4. The game displays the round winner and updates the score.
5. Repeat until you stop.

## Installation
Clone the repository and open the HTML file:

```bash
git clone https://github.com/BinaryVortex/Rock-Paper-Scissors-2.git
cd Rock-Paper-Scissors-2
# Open index.html in your browser (double-click or use your editor's preview)
```

No build step or dependencies required.
